# 公理

## AXIOM-01：状态不等于证据

Passport 记录材料处于什么状态，不能替材料证明事实。

## AXIOM-02：原始材料留在原位

Passport 保存路径或稳定标识，不复制和改写原始材料。

## AXIOM-03：判断和未知项分开

没有证据支持的内容进入未知项或标为推断，不能进入已确认判断。

## AXIOM-04：交接必须可追溯

每次交接记录来源阶段、目标阶段、材料 ID 和接收状态。

## AXIOM-05：状态变化保留理由

材料、判断和交接状态改变时追加审计记录，不覆盖旧记录。
材料内容变化时保留旧版本，用新 ID 登记新版本；依赖旧版本的判断和交接不能静默沿用。

## AXIOM-06：讨论决定留下凭据

会议、头脑风暴或人机讨论形成决定后，为每个决定记录参与者、权限、范围和原始记录位置。

## AXIOM-07：Credential 不证明结论正确

Credential 证明系统记录了什么决定。内容 Hash 检查记录是否变化，不能替代证据核验、专业审查或人类确认。

## AXIOM-08：决定改变时保留旧凭据

不改写旧 Credential。新 Credential 通过 `supersedes` 指向被替代记录。
