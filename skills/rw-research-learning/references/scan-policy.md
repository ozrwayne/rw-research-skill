# 扫描策略

## 范围

| 模式 | 根目录 | 使用情形 |
|---|---|---|
| `folder` | 用户指定的一个或多个目录 | 用户长期在固定位置保存内容 |
| `current` | 当前工作目录 | 用户在一个项目里学习或研究 |
| `user` | 当前环境可读的用户主目录 | 用户明确要求全量盘点 |

拒绝将操作系统根目录作为扫描根。运行环境限制可读范围时，报告实际覆盖范围。

## 两阶段扫描

1. `landscape` 只读取路径、扩展名、大小和修改时间，用于发现候选内容目录。
2. `scan` 只对最终选择的根目录提取正文并建立索引。
3. 用户说“只看这个文件夹”时，不扩大范围。
4. 指定文件夹和自动发现目录分别记录，不能把候选范围说成已经完成内容扫描。

## 默认排除

- 版本库、依赖包、虚拟环境、编译目录、缓存、回收站、操作系统库和应用程序目录。
- 隐藏目录，除了扫描根目录本身。
- `.env`、私钥、证书、密码库、凭据文件和常见密钥文件名。
- 索引自身的 `.rw-research/` 目录，以及本次实际指定的任何名称的状态目录。
- 超过默认大小限制的文件。
- 符号链接指向的目录和文件。

## 提取状态

- `indexed`：已提取可用文本。
- `partial`：文件可读，但只提取了前部分文本。
- `unsupported`：识别到文件，当前没有可用提取器。
- `too_large`：文件超出大小限制。
- `sensitive`：文件类型或文件名命中敏感排除规则。
- `unreadable`：权限或解析错误阻止读取。

## 增量扫描

1. 比较文件大小、纳秒修改时间、ctime 和提取策略版本；大小或文本上限变化也重新提取。
2. 未变更且上次提取成功的文件保留文本和状态；敏感规则先于缓存复用，unsupported／unreadable 项重试。
3. 新增和修改文件重新提取。
4. 完整遍历确认未出现的文件才从索引移除，按路径覆盖范围处理父子根切换。遍历或 stat 失败时保留未观察记录的旧文本，并标记 unreadable，检索不返回这些旧观察。
5. 每次扫描写入时间、根目录、各状态计数、private_local 和 complete。退出码 0 表示扫描进程完成，不保证所有材料可读；complete=false 及 retained_unverified 必须报告。

## 内容最小化

- 索引保存用于本地检索的提取文本。
- Agent 只读与当前主题有关的命中和原文样本。
- 不将全量索引复制到对话、公开仓库或远程服务。
- 用户删除状态目录后，本 Skill 不保留另一份副本。

## 私有状态

- 扫描索引、manifest、研究画像和能力报告默认为 `private_local`。
- 不自动复制到 README、示例、测试、公开仓库、Release 或远程服务。
- 公开测试只使用合成材料，不使用真实文件名、路径、人物、机构、研究内容或能力判断。
- 用户没有明确要求时，不导出或分享本地状态。

## 输入、私有状态与限制

- 文件大小、文本长度、发现深度和返回条数必须为正整数。状态目录不得等于或包含内容根目录。
- 只提取普通文件；跳过符号链接、FIFO 等特殊文件。显式选择 credentials、secrets 或常见密钥目录作为根，也不提取其正文。
- 新状态目录权限为 0700，数据库及原子写入的 manifest 为 0600（按系统权限语义执行）。已有父目录不批量改权限。
- 已有数据库在任何权限修改、WAL 或迁移前检查文件身份、application_id 和索引表结构；拒绝符号链接、多硬链接和未识别的其他数据库。兼容旧版本索引时，不接受带无关用户数据表的共用数据库。
- `query`、`discover`、`stats` 只读已存在的数据库；缺索引时报错，不创建“空扫描成功”的状态。
- 支持带 BOM 的 UTF-16；损坏 Office XML 报 unreadable。选中 Office XML 单项上限 32 MiB、总计上限 64 MiB；压缩文件大小不会代替展开大小检查。
- 缓存仍是本地文件元数据驱动，不是内容签名证明；文件系统被并发修改、特定文件系统不可靠地更新 ctime 时应重新核对原文。索引文本 hash 是已提取文本的 hash，不等于完整原文件 hash。
- 同一状态目录的 CLI 扫描使用 `.scan.lock` 串行化，覆盖数据库迁移、事务提交和 manifest 原子替换；外部手工写库或直接调用 Python 内部函数需由调用者协调。manifest 原子替换避免截断，进程在数据库提交后异常终止仍可能使 manifest 落后一轮，此时以数据库 scan_runs 为准并重新扫描。
- 文件名排除规则不是秘密内容识别器；不要把未知来源的敏感目录作为研究资料根。
