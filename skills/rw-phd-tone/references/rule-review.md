# 新语气规则审查

只在从作者样本抽出新规则时用。用已有规则复查草稿时不用。

每条新规则逐个回答下面六个问题：

1. 清楚：别人读了这条规则，能照着改出同样的句子吗？
2. 个人还是领域：这是作者本人的习惯，还是这个领域人人都这样写？领域通用的写法记为体裁参考，不记为作者指纹。
3. 能被样本推翻：能找到作者没这样写的样本句吗？找到了，写明适用范围或删掉这条。
4. 能操作：这条规则能落成一种具体改法吗？
5. 有没有替作者做判断：这条规则有没有偷偷改了论证、结论强度或取舍？有就删掉，交回写作流程。
6. 导师留白：协作模式下，这条规则会不会把留给导师改的地方提前改掉？

有一个问题答不上，这条规则标为临时规则，写明缺什么样本。
