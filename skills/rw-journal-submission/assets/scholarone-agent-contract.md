# ScholarOne Submission Agent 合同

## 输入

- 已验证的 `Submission Packet`。
- 用户已登录的 ScholarOne 页面。
- 用户对本次填入范围的确认。

## 执行

1. 先读取当前页面和每一步的错误。
2. 将页面字段对应到资料包中的已确认字段。
3. 只填写本次获确认的字段。
4. 每次保存后重新读取页面，记录错误是否消失。
5. 将页面步骤、错误和保存时间写回资料包的 `portal` 与 `audit_log`。

## 职责

- 人类确认作者、披露、伦理、审稿人冲突和稿件内容，并完成最终 `Submit`。
- 主 Agent 只填写已确认字段、执行普通保存、保存后复读和记录页面状态。
- 本地材料 worker 只整理本地材料、检查一致性和运行本地测试，不登录或操作门户。模型选择服从用户本轮限制；用户允许时可使用 Luna，模型名不改变权限边界。
- Skill 提供流程、字段结构、停止条件和脚本，不执行页面动作。

## 停止

- 作者邮箱、作者顺序、通讯作者、CRediT、披露或审稿人资料未确认。
- 页面出现验证码、支付、权限变更或最终提交。
- 页面字段不能与资料包可靠对应。
- 保存后出现新的错误或原有错误没有减少。

## 最终提交

Agent 到 `Review & Submit` 页面后停止。最终 `Submit` 始终由人类完成。人类告知提交结果后，Agent 记录 `user_confirmation`；Agent 读到平台回执后，再记录 `platform_receipt`。
