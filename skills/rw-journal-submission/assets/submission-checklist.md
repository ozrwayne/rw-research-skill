# 投稿检查表

- 期刊范围与论文问题一致。
- 当前作者名单、单位和通讯作者已确认。
- 主文、摘要、图表、补充材料和数据声明版本一致。
- 当前指南要求图表单独上传时，展示项清单已记录编号规则、正文引用、对应文件和上传顺序；`preflight-display-items` 已通过。
- 字数、引用和图表格式符合当前指南。
- Cover Letter 没有加入论文未支持的主张。
- 伦理、利益冲突、基金和数据可用性声明已核对。
- 投稿文件名和最终版本已记录。
- Submission Packet 已记录作者、披露、审稿人、门户步骤、缺口和最终递交证据状态。
- 校样文字检查和视觉检查已分开记录；无法由 Agent 读取的 PDF 已交给人类核对。
- 退回稿已记录原始理由、修复动作和保存证据，未新建投稿。
- 门户中的已保存草稿不写成已提交。最终 `Submit` 由人类完成；Agent 只在用户告知结果或读到平台回执后记录状态。
