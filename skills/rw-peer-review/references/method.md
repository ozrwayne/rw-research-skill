# 方法

## 输入门

- 期刊名称、稿件版本和稿件位置。
- 参与本次评审的 Agent 和它们的模型来源。
- 允许引用的证据来源。

## Agent 配置

按期刊定领域，只读摘要和关键词生成 Agent 身份。默认两个打分 Agent（方法、领域）、一个唱反调 Agent、一个综合 Agent。两个打分 Agent 互相看不到对方的报告。

## 两阶段

1. 读全文之前写下判定标准：查什么、什么算不过。
2. 读全文之后按已写下的标准判断。改标准要先声明改哪一条和为什么。

## 三个角度

1. 值不值：读前读后多知道了什么，差值对着一篇具体的近期文献说。
2. 真不真：怎么才算假、对照在哪、样本量撑不撑得住、测的是不是想测的。
3. 范围：写出数据支持的最窄说法，和标题摘要并排比。

## Gate

- PASS：所有意见都有下场。
- REVIEW：还有未处理的非阻断意见。
- BLOCK：还有未处理的阻断意见。

Gate 是意见处理状态，不是稿件质量评分。
