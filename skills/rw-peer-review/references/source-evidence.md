# 来源证据

- 同行评审要求意见可定位、可追溯、可复核。
- 独立评审要求评审人之间不互相参照，避免制造重复意见。
- 评审记录与作者本人的研究档案分开保存，避免读取时混淆两类材料。
- 当前 Skill 把这些要求变成可验证 JSON 和 gate。
- Cognitive Apprenticeship、自我解释和元认知监控支持“机器先映射，用户先判断，再接受反馈”的顺序。
- 论证结构和去偏研究支持同时记录主张、依据、最强质疑、最强回应和改变判断所需证据。
- COPE 与 EQUATOR 的同行评审指南支持客观、可定位的意见，并要求区分报告不足与研究设计问题。
- ASA p-value statement、统计误读指南和交互模型论文支持把显著性分类、估计值、不确定性、条件效应和结论变化分开。
- ICH E9(R1) 和因果推断教材支持核对研究对象、目标效应、分析和敏感性分析是否对齐。
- 这些来源用于设计核对流程，不替代对当前稿件、补充材料和作者回复的逐项检查。
- W3C PROV 支持实体、派生、集合、责任和失效的 provenance 表达；PROV Constraints 支持唯一性、顺序、类型和一致性检查。
- W3C Verifiable Credentials Data Model 2.0 区分 claims、evidence、schema 和 status，并明确结构可验证不等于主张为真。
- RO-Crate 支持用稳定 ID、根实体和交叉引用聚合研究材料及 provenance。
- 本 Skill 只借用这些建模逻辑，不实现数字签名、交换协议或 JSON-LD 标准兼容。
