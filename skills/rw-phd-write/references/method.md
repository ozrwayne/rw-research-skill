# RW PhD Write 方法

## 输入门

- 保留用户原问题和原始材料。
- 确认交付物、研究类型、可用证据和不能越过的范围。
- 缺少会改变判断的信息时，只追问必要项；其余内容继续处理。

## 执行阶段

1. 建立 research output profile，确认研究问题、读者、材料、语言、输出形式和作者批准的修改范围。
2. 根据上下文判断章节、小节和段落功能，不从章节编号推断功能。读取 `references/content-necessity-gate.md`，先判断必要性、位置与完整性。
3. 写前区分此处必需、上文已说明、应放别处、不应加入及仍缺证据／作者决定的内容；标明关键研究决定的确认状态。
4. 对需要的内容建立 function-to-claim-to-source 骨架，再生成正文。不要把内部检查表写成公开段落，不用通用对照或意义句填充缺口。
5. 对已有稿件或生成结果，在完整论证单位中先选择 KEEP、DELETE、MERGE、MOVE、REWRITE、NEEDS_EVIDENCE 或 AUTHOR_DECISION；批注用词不预先决定修改动作。检查范围可以扩大，实际修改范围须有作者批准。
6. 检查删除或移位的真实损失以及全文重复；保留必要定义、反证、不确定性、报告和复现细节。删除可以没有替代文字，合格内容允许零修改。
7. 仅对确需保留的内容运行概念闭合检查：当前功能所需的主体、对象、行动、关系、边界和意义可由文字及上下文识别，不逐句凑齐字段。
8. 检查读者推断断点，有证据才补关键连接；证据不足保持缺口。对照与总括的专项判断读取 `references/abstract-contrast-gate.md`，不按关键词删除。
9. 核对来源、研究类型对应的报告责任、主张强度和作者语气；检查遗漏、悬空指代、跨章重复及删除内容是否以同义表达回流。
10. 分开记录冗余处理、无据主张处理和论证完成状态，再交给引用核验及交付检查。删除唯一但无依据的研究理由后，论证仍保持 unresolved。

## 证据门

- 每项事实能回到用户材料或可核验公开来源。
- 推断标记为推断，缺失标记为缺失，不用常识补成已知事实。
- 当前信息在使用当日核验；稳定方法使用 Skill 内的摘要。
- 报告规范、偏倚工具和研究设计各自承担不同功能。
- 章节编号不能替代功能判断。
- 解释义务随功能变化，不把 evidence、interpretation、why it matters 和 research-question link 机械加入每一段。
- 对需要保留的论证，关键逻辑不能只存在于作者脑中；无法由现有证据支持的连接保持为缺口。
- 抽象关系词不能充当解释的终点。使用 route、option、factor、decision、process 或 implementation 时，要让读者知道该词具体指向谁、什么对象和什么行动。
- 概念闭合以“不再需要猜关键关系”为停止条件，不以篇幅或句数为目标。

## 输出契约

- 章节、段落或论证骨架。
- research output profile、function-to-claim-to-source 表和引用缺口。
- 写作功能判断、解释义务、概念闭合断点、读者推断断点和未完成项。
- 修改说明、未解决问题和下游核验状态；按任务规模只展开必要部分。

输出同时标记：已确认事实、当前判断、来源、未知事项、停止条件和下一步。

## 停止条件

- 没有来源时，不生成事实性引用或伪造 DOI。
- 没有研究结果时，不写成研究已完成。
- 没有证据支持重要性或研究问题连接时，标记为作者判断或证据缺口，不生成通用意义句。
- 没有扩改确认时，不修改用户限定范围之外的内容；审稿意见和论证诊断不等于作者授权。
- 不为流畅删除限制、反例和不确定性。
- 不把 Skill 输出当成作者最终责任或期刊合规确认。

## 内容取舍验收

- 生成前和修改前均按 `references/content-necessity-gate.md` 判断内容与位置，之后才修补表达。
- 删除不要求替代句；保留不要求改写。无据主张被删除不代表研究理由已经成立。
- 验收包含零稿、续写、不同上下文、必要限定、报告细节、反证、跨章重复及多轮回流；不按删字比例评分。
