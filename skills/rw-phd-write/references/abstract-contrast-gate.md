# 抽象对照与空总括检查

Abstract Contrast and Empty Summary Gate 是本 Skill 的工作规则名称，不是正式语言学分类或 AI 作者身份检测工具。它接在既有概念闭合、读者推断检查中；生成和复查是两个阶段，不额外强制调用其他 Skill。

## 适用与判定

用于科研文本中的对照、总括和研究过渡，或处理 AI-like、缺少 key message 等反馈。先确定完整论证单位和用户允许修改的范围，再检查目标句、必要的相邻句及所在段落。用户只要诊断时，只给诊断。

以下是线索，不是必须同时满足的条件，也不是自动判错规则：

- 两个未具体化的概念只被宣布为不同，没有交代相关区别。
- 句子看似总结或转折，实质信息全部由相邻句承担。
- 换成肯定句或同义术语后，依然没有表达可识别的主张。
- 删除后事实、论证关系和读者理解均无损失。

认定需要修改时，说明该句在当前上下文缺少什么主张或功能。抽象程度高、没有新数字、出现 `not/but`、句子短，均不单独构成问题。已在上文定义的概念可以直接使用；有功能的主题句、过渡句、总结句及必要的科学限定应保留。中英文使用同一判断标准。

## 生成：先表达可支持的主张

1. 从当前材料写出段落要让读者理解的判断和证据边界，而非先写口号式起句。
2. 使用对照时，让读者在必要的上下文中识别比较对象、具体差异以及该差异在当前论证中的作用。只检查相关要素，不要求每句包含主体、行动、结果和场景等全部字段。
3. 材料已有具体信息时直接使用；删去无作用的预告句，或合并重复信息。材料缺少关键关系时，区分作者意图待确认与事实证据待补，不自行创造具体性。
4. 保留限定、犹豫、反例和作者语气；不为避开某种句型制造新的模板或拉长句子。

## 复查：诊断、动作和修改结果分开

检查以下问题，而不是逐个关键词打分：

- **指向**：读者是否知道概念在这里指什么？答案可来自上文，不强迫每句独立复述定义。
- **命题**：当前论证需要的区别、关系或判断是否已经说清？
- **作用**：即使没有新事实，该句是否帮助组织证据、提出主张、导航或限制结论？
- **删除**：删除后事实、推理连接和理解是否同时保持？有损失时保留其必要功能。
- **相邻关系**：信息是否重复，是否存在更小幅度的合并或具体化方案？

只在有实际问题或用户要求详细审计时展开记录：

| 字段 | 约定 |
|---|---|
| `verdict` | `PASS`、`NEEDS_REVISION` 或 `NEEDS_CONTEXT` |
| `location / quote / context` | 原句位置、原文和必要上下文；缺少位置时如实说明 |
| `reason` | 具体的主张或功能问题，不以“像 AI”代替解释 |
| `action` | `KEEP`、`DELETE`、`MERGE`、`REWRITE` 或 `ASK_AUTHOR` |
| `gap` | 按需记录 `AUTHOR_INTENT` 或 `EVIDENCE`，区分意图与事实缺口 |
| `postcheck` | 动作为建议、已实施或待确认；实施后记录主张一致性及段落复核结果 |

`PASS` 对应 `KEEP`；`NEEDS_CONTEXT` 通常为 `ASK_AUTHOR`。证据缺口并非必须由作者回答：可在当前授权范围内核验来源，仍未补齐时保持待核验。`NEEDS_REVISION` 根据上下文选择删除、合并或具体化；建议不等于修改授权。

## 修改后的主张一致性检查

比较原句、改句及对应材料：主体／人群、条件、量词、比较对象、结果、否定与因果强度、不确定性、引用位置与支持范围是否保持？例如，将“这两项研究未报告运营成本”改成“试验不研究运营成本”，属于范围扩大，不因表达更直接而通过。

通过流程为：草稿 → 定位问题 → 最小修改 → 主张一致性检查 → 段落复核。已确认的空话不留在标为完成的稿件中；依赖作者决定或新证据的部分明确保持待处理。建议改写仍有疑问时收窄或回退，不反复同义改写；不为追求零标记而删掉有用内容。同一 Agent 的第二遍复查不称为独立验证。

修改 Word 等文档时保留引文字段、评论、修订及未经批准的相邻文字。新增或扩大事实主张进入来源核验；没有来源时保留缺口，不把可读性修订当成事实验证。

## 合成例子

- **需要合并或删除**：“The testing question is not the delivery question. In the pilot, research assistants sent every reminder; the report did not identify who would send reminders in routine service.” 第一句未增加必要功能；保留后一句中的主体和报告边界。
- **肯定句仍可能空泛**：“Delivery constitutes a separate dimension.” 换掉否定结构未补足实际关系，按上下文继续判断。
- **具体对照应保留**：“In this sample, reminders increased attendance but did not change the cancellation rate.” 对象、结果和适用范围清楚；这仅为合成输入，不代表真实研究结论。
- **组织功能应保留**：“Costs arose at different stages.” 后文分别介绍购置与维护成本时，可承担有效主题句功能，不要求另加数字。
- **科学限定应保留**：“The association may reflect differences in staffing.” 当材料只支持观察性关联时，保留不确定性，不改写成确定因果。

## 行为验证边界

`references/behavior-tests.json` 中 `gate = abstract_contrast_v1` 的 12 组合同分别提供生成输入 `generation_prompt` 和复查输入 `prompt`，覆盖应修改、应保留和修改边界，各 4 组。期待行为用于评分，不放入运行提示。

保存输入、输出、Skill 版本／hash、执行者、发现项和复核结果。分别记录漏检、误删、主张漂移与无必要扩写；词频、关键词命中或静态自检不替代语义判断。当前合同是开发／回归材料，不冒充未见留出集。

比较旧版与新版时，使用同一模型、相同输入与条件、互不继承的会话，并保留两侧原始输出。新验收材料预先冻结，与用于调整规则的案例分开；若已用于调整，移入回归集合。缺少实际旧版输出或干净会话时，标记比较未执行，不推算改进率。同一 Agent 的演练单列记录，不作为独立或跨模型效果证明。
